# Changelog

What changed in each released version, newest first. Every `vX.Y.Z` section here is published verbatim as that release's notes, and Settings shows those notes to a reader deciding whether to update — so each bullet is a plain sentence, with no Markdown emphasis. See [CONTRIBUTING.md](CONTRIBUTING.md#cutting-a-release).

## Unreleased

- Standup Post is now Work Summary: Notes and completed work for a selected period with all current commitments, generated by a model on request.
- Work Summary Material copies the selected period's records without a model configured, separately from the generated prose.
- Settings holds a Work Summary Prompt with a new default; old Standup Prompt values are not carried over.
- Work Summary has its own date-range calendar and presets, independent of History, opening on This week.

## 0.13.0 — 2026-09-08

- Settings has a What's new group: what the running version changed, from the changelog the app shipped with, and every earlier version a press away. No check for updates, and no network.

## 0.12.0 — 2026-09-08

- Settings shows what a release changed before you install it: the version's changelog, from the release itself, under the Updates control and up until the app restarts into it.
- The README is now the page a user reads, and the contributor instructions moved to CONTRIBUTING.md.

## 0.11.1 — 2026-09-07

- Copies are named by what they contain — Digest, Standup Material, Review Material — and each surface offers exactly one copy control instead of two that looked alike.

## 0.11.0 — 2026-09-07

- First launch walks through Onboarding: what the app is, the Hotkey, Start at Login, and a replay from Settings if you want it again.
- Onboarding has you capture a practice Note and then find it in History.
- Meeting Import and Model Access are offered as Onboarding steps, so the two settings that need your input are asked for once rather than discovered later.

## 0.10.1 — 2026-09-06

- Backup retention now prunes the oldest snapshots instead of the newest, and a restore is staged atomically so a failed one leaves the journal untouched.
- Restore candidates are validated by their columns, not only their table names, and impossible dates are refused in snapshot names and in refiling.
- The Model Base URL must be https before the API Key is attached to it, and a URL's own query or fragment survives the chat path being joined onto it.
- Every pending Task Alert keeps its Complete action, not just the last one, and a completed slot can never be reopened by editing the series.

## 0.10.0 — 2026-09-04

- The journal backs itself up automatically and on demand, and can be restored from any snapshot.
- History offers Review Material, a lossless rendering of the selected range for a model to read.
- Tasks can be searched by what they say.
- A Task can only be completed at the slot it still holds.
- The download page was rebuilt around what the app has become.

## 0.9.1 — 2026-09-03

- Standup Material can be copied without a model configured.
- Completed Task Occurrences are included in the Standup Post.
- A Project can be renamed or merged across every Note filed under it.
- macOS notifications arrive under the app's own identity again.

## 0.9.0 — 2026-09-02

- The app updates itself: Settings › Updates › Check for updates downloads the next version and restarts into it, with no DMG and no terminal.

## 0.8.2 — 2026-09-02

- Every settings save is confirmed with a toast.
- Settings sits at the end of the Main Window sidebar.

## 0.8.1 — 2026-09-01

- Settings text inputs sit below their labels.

## 0.8.0 — 2026-09-01

- Standup Post: the day's Notes and Tasks written up as a post, generated by a model.
- Model Access lives in Settings, with the API Key in the macOS Keychain.
- Settings seed only the values you have not already changed.

## 0.7.2 — 2026-08-31

- Task rows lay out better, and scheduled rows show the year.

## 0.7.1 — 2026-08-31

- Internal only: the names shared between Rust and TypeScript are checked by a test.

## 0.7.0 — 2026-08-27

- One Main Window holds History, Tasks and Settings as sections, with a menu bar of its own and a Dock icon while it is open.
- A Capture or a Task you were typing survives the Main Window opening.
- Dismissing a Capture hands focus back without hiding the app.

## 0.6.1 — 2026-08-27

- An empty date field no longer claims today's date.

## 0.6.0 — 2026-08-26

- Tasks: create, manage, complete and export them.
- Tasks can recur, and each Task Occurrence keeps its own history.
- Scheduled Tasks deliver local macOS Task Alerts.

## 0.5.1 — 2026-08-25

- Patched eight dependency advisories in the lockfile.

## 0.5.0 — 2026-08-25

- A designed interface throughout: palette, type scale and icons, applied to the Capture, History and Settings windows and to the window chrome.
- Today's meetings can be imported as Notes, skipping all-day events.
- The tray shows today's Captured Note count, the Hotkey it answers to, and offers yesterday's Digest.
- The Capture window grows to fit its Project Predictions.

## 0.4.1 — 2026-08-11

- Settings shows the app version.

## 0.4.0 — 2026-08-05

- Projects are first-class filing: a Capture assigns one with a leading `#name`, offers Predictions as you type it, and History narrows by Project and can refile a Note.
- Filter Presets: one-shot named ranges on History.
- Day Start is gone — a Journal Day is the local calendar day the Note was captured in.

## 0.3.4 — 2026-08-02

- The Tray Menu no longer closes immediately on the first click.
- A window opens in the palette it is going to keep.

## 0.3.3 — 2026-08-02

- The Capture window's corners are rounded.

## 0.3.2 — 2026-08-02

- Dates and times are written the way your own machine writes them.
- A Note takes the width of the window it is in, and the Digest button is named after the Digest.
- A refused Capture says so instead of leaving a window open.

## 0.3.1 — 2026-08-01

- The Search field gives way so Copy All stays on screen.

## 0.3.0 — 2026-08-01

- Search finds a Note by what it says and goes to its day.
- History reads one day as the Filter it is.
- A correction that fails is reported rather than silenced, and a Journal Day the journal cannot have been written in is refused.

## 0.2.0 — 2026-07-29

- Dark mode, accessible names, and a failed render that says so instead of showing nothing.

## 0.1.2 — 2026-07-27

- The app's mark appears where each surface expects it.

## 0.1.1 — 2026-07-27

- An icon of its own, a page to be downloaded from, and a separate journal for dev builds.

## 0.1.0 — 2026-07-27

- First release: a menu-bar app that captures a Note from the Tray Menu or a global Hotkey, keeps it in a local journal, and shows it in History — where a range can be selected, a Note edited, refiled or deleted, and the Filter copied out as a Digest. Settings holds the Hotkey and Start at Login. Pushing a version tag publishes a DMG.
