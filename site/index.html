Local-first work log · Notes + Tasks

The day’s work, written down before it evaporates.

Work Journal lives in the menu bar. One hotkey captures a one-line Note about what you just did, another creates a Task for what is still to do. At standup time, yesterday reads back as Markdown — or as prose, written by your own model.

Download for macOS See how it reads back

Unsigned DMG — one xattr command after install, then in-app updates from there. Details at Download.

  • ✓ No account, no server. Notes and Tasks are a SQLite file on your Mac.
  • ✓ Export everything to Markdown any time. Nothing is locked in.
  • ✓ The network is touched only for a standup post you request and an update you confirm.

How it works

          

            Capture in a keystroke, file as you type, read back as Markdown.
          

          

            Three moments in order — during the day, at the boundary, the
            next morning. That order is the whole product, so it is the one
            numbered list on this page.
          

          
    
            
  1. 
              01 — Capture
              
    One line, then gone
    
              
    
                The Note hotkey opens a text field over whatever you are doing.
                Write the line, press Enter, the window is gone.
              
    
              
    #api fixed retry storm on checkout
    
            
    2. 
            
  2. 
              02 — File
              
    The marker is the filing
    
              
    
                Start the line with #name and the Note is filed
                under that Project. Names you used are offered as you type.
              
    
              
    
                #website rewrote hero, kept the xattr note

  3.

Capabilities

          

            Everything around that loop, and nothing else.
          

          

            The app’s vocabulary is small on purpose: Notes recover work
            that happened, Tasks hold work still to do. These groups sit side by
            side — none comes before the other.
          

          

            

              
Notes

              
History you can actually search

              
    
                
  • Capture from the hotkey, the tray menu, or relaunch.
    • 
                
  • 
                  Read any range — today, yesterday, this or last week or
                  month — narrowed to one Project or not at all.
                
    • 
                
  • 
                  Search every Note’s text to jump to the day it is filed
                  under.
                
    • 
                
  • Reword, refile to another day, or delete. No trash.
    • 
              

            

            

              
Tasks

              
Commitments with a schedule

              
    
                
  • 
                  Its own hotkey and an always-ready window; Enter commits one
                  Task.
                
    • 
                
  • 
                  A date, with a time to the minute — past dates are valid
                  and read as overdue.
                
    • 
                
  • 
                  Daily, weekly, monthly, yearly, or every N — one open
                  occurrence, never a backlog of missed ones.
                
    • 
                
  • 
                  A dated Task with a time raises a local macOS alert. No
                  sign-in, nothing sent anywhere.
                
    • 
              

            

            

              
Standup Post

              
Yesterday, written up when you want it

              
    
                
  • 
                  Yesterday’s Digest from the tray — Markdown,
                  nothing to configure.
                
    • 
                
  • 
                  Standup Material one click in: Notes plus work kept plus open
                  Tasks due. Paste it as-is with no model.
                
    • 
                
  • 
                  Or a Standup Post in prose from exactly that material —
                  read it before copying; it may be wrong and is never kept.
                
    • 
              

            

            

              
Meetings & the rest

              
The day, even what you forgot

              
    
                
  • 
                  Today’s macOS calendar meetings can become Notes on
                  their own. Off until you pick the calendars.
                
    • 
                
  • Copy the range on screen; Export the whole journal.
    • 
                
  • 
                  Remap both hotkeys, follow the system theme, start at login,
                  recover alert permission from Settings.
                
    • 
              

            

          

        


        

          

            
Download for macOS

            

              Apple Silicon only. The build is unsigned, so macOS quarantines
              the download — the command on the right clears it once. From
              then on, Settings finds updates and installs them itself.
            

            Download for macOS
            

              Latest release  ·
              
            

          

          

            

              After dragging it to Applications — required, once
            

            

              
xattr -dr com.apple.quarantine "/Applications/Work Journal.app"

              
            

            

              A copy you compiled yourself was never quarantined and needs
              nothing. Updates need nothing either — the app unpacks its
              own signed payload and restarts into it.
