How it works

          

            Capture in a keystroke, file as you type, read back as Markdown.
          

          

            Three moments in order — during the day, at the boundary, the
            next morning. That order is the whole product, so it is the one
            numbered list on this page.
          

          
    
            
  1. 
              01 — Capture
              
    One line, then gone
    
              
    
                The Note hotkey opens a text field over whatever you are doing.
                Write the line, press Enter, the window is gone.
              
    
              
    #api fixed retry storm on checkout
    
            
    2. 
            
  2. 
              02 — File
              
    The marker is the filing
    
              
    
                Start the line with #name and the Note is filed
                under that Project. Names you used are offered as you type.
              
    
              
    #website rewrote hero, kept the xattr note
    
            
    3. 
            
  3. 
              03 — Read back
              
    Yesterday, ready to paste
    
              
    
                The tray copies Yesterday’s Digest with no window open.
                One click further gives the Standup Material or a Post.
              
    
              
    ## Yesterday
- #api fixed retry storm…
    
            
    4. 
          

        


        

          
Capabilities

          

            Everything around that loop, and nothing else.
          

          

            The app’s vocabulary is small on purpose: Notes recover work
            that happened, Tasks hold work still to do. These groups sit side by
            side — none comes before the other.
          

          

            

              
Notes

              
History you can actually search

              
    
                
  • Capture from the hotkey, the tray menu, or relaunch.
    • 
                
  • 
                  Read today, yesterday, this or last week or month, per
                  Project or all.
                
    • 
                
  • Search text to jump to the day it lives on.
    • 
                
  • Reword, refile, or delete. No trash.
    • 
              

            

            

              
Tasks

              
Commitments with a schedule

              
    
                
  • 
                  Its own hotkey and always-ready window. Enter commits one
                  Task.
                
    • 
                
  • 
                  A date, with an optional time. Past dates read as overdue.
                
    • 
                
  • 
                  Daily, weekly, monthly, yearly, or every N. One open
                  occurrence, never a backlog.
                
    • 
                
  • 
                  A dated Task with a time raises a local macOS alert. Nothing
                  leaves your Mac.
                
    • 
              

            

            

              
Standup Post

              
Yesterday, written up when you want it

              
    
                
  • 
                  Yesterday’s Digest from the tray. Markdown, nothing to
                  configure.
                
    • 
                
  • Standup Material one click in. Paste as-is with no model.
    • 
                
  • 
                  Or a Standup Post in prose. Read before copying; never kept.
                
    • 
              

            

            

              
Meetings & the rest

              
The day, even what you forgot

              
    
                
  • 
                  Today’s calendar meetings can become Notes. Off until
                  you pick calendars.
                
    • 
                
  • Copy the range on screen; Export the whole journal.
    • 
                
  • Remap hotkeys, follow system theme, start at login.
    • 
              

            

          

        


        

          
About

          
Built for standup time.

          

            

              I built Work Journal because every standup asked what I did
              yesterday, and my answer came from memory and chat history. Now
              it comes from one-line notes I typed as the work happened.
            

            

              It isn’t trying to be a project manager, a knowledge base,
              or a second brain. Notes recover what happened, Tasks hold what
              remains — everything else lives somewhere else.
              That’s it.
