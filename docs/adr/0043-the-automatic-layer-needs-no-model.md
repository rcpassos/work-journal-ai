# The automatic layer needs no model

Observing turns a source event into a Note, and the line it stores is already the user's own prose about their own work: a commit subject, the prompt the user typed. Nothing has to be extracted, classified or rewritten, so the automatic layer needs no model at all — the same reason Tasks need no model (ADR 0015). "add check for updates to tray menu" is a journal line already, written by the person whose journal it is; a model asked to improve it would add a network call, a cost and a chance of drift without adding a fact, and the journal has to work with no account and no network the way everything else here does. Where synthesis belongs it already is: a Work Summary is prose written from the records, with a model, when the user asks for one. Rejected: classifying free text into Notes and Tasks at the source; rewriting subjects into past-tense journal lines (the subject is the provenance, and the Body is editable forever anyway); parsing each tool's session files to look for material worth summarising — the user's own line is the material, and reading those files is the treadmill of shifting formats that #254 measured.
