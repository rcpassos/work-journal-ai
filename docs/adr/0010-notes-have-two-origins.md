# Notes have three origins

A Note comes into existence by Capture — the user typing one — by Import, which turns a meeting on the user's calendar into a Note without being asked, or by Observe, which turns a selected source event about work that happened into a Note. Note therefore stops meaning "text the user wrote", and Captured At stops meaning "when the record was stored": it is the instant the Note is *about*, so a meeting swept up at 18:40 or work observed after midnight still sorts into the day it happened in rather than collapsing a whole day onto one timestamp. An Imported Note is otherwise an ordinary Note — its Body is the event title verbatim, it is Unfiled, and it is editable, refilable and deletable like any other. An Observed Note is ordinary in the same way, except its source may choose a Project. Both retain provenance on the Note, which survives edits and refiling; historical Imported Notes from before provenance was stored keep null source fields. Rejected: proposing meetings or source events for confirmation before they become Notes (deletion already exists and is permanent, so refusing is cheaper than confirming, and a missed event is never noticed); a separate event record beside Note (a second unit destroys "the unit of everything — there is no smaller or larger record").

## Consequences

Imported and Observed Notes never Nudge — a Nudge means "you wrote something on another day", which is a fact about the user, not about an automatic record. Once created, a Note stops following its source: later calendar changes or source edits do not rewrite it, and the user's edits win. Deleting an Imported or Observed Note also refuses its source event permanently, which forces the app to remember which events it has already handled *separately from the Notes*, since the Note itself is gone. A handled event is identified by the source and event key together, so sources cannot collide. The Tray Count remains Captured Notes only, because a count inflated by automatic records would reassure the user precisely on the days they typed nothing. Digest and Export show the Body once, without provenance.
